# 🌊 Moana Fan Hub

A simple fan website dedicated to Disney's Moana.

## Features

- Responsive modern design
- Hero section with ocean-themed background
- Character showcase carousel
- Popular Moana songs section
- Information about the world of Motunui
- Smooth scrolling navigation
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Outfit)
- Lottie Animation

## Project Structure

```
project/
│
├── index.html
├── styles.css
└── README.md
```

## How to Run

1. Download the project files.
2. Open `index.html` in your web browser.
3. Explore the Moana Fan Hub.
